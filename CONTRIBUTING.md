# Contributing

Bug reports, ideas, ports, and pull requests are welcome.

For bugs, include your Minecraft, Forge or NeoForge, and World Souls versions, plus how to reproduce the problem. A screenshot or the relevant log helps. Remove access tokens and personal information before posting logs.

Fork the repository and start from the branch for the version you want to change. Create a branch for your fix, then open a pull request against that version branch.

Keep changes focused and follow the existing formatting. Include what changed and which versions you tested. Build commands are in each version's README.

For bigger changes to the generator, open an issue so we can talk about the idea first. Weird names and happy accidents are part of the fun.

Contributions use [CC BY-NC-SA 3.0](LICENSE). Keep the credits and third-party notices with anything you reuse.
