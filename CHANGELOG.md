# Changelog

## 1.0.0

- Dice button beside the World Name field.
- Procedural names from 3 to 16 characters, with occasional apostrophes and Roman numeral designations.
- Fragments inspired by mythology, science fiction, and game worlds.
- Brief world-name arrival title and a small name display in the pause menu.
- Generated, custom, and renamed local worlds use the same name displays.
- Client-side builds for Minecraft 1.12.2, 1.16.5, and 1.20.1 on Forge, and 26.3 on NeoForge.
